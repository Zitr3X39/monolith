Подключение

Выбери, куда подключаешь

Везде одно и то же: скопировал команду — вставил. Сервер общий, подключать можно сразу везде и с любого устройства.

Notion

Настройки → Connections → Add MCP server. Или прямо в чате: «подключи MCP-сервер».

  1. В поле MCP server URL вставь адрес сверху.
  2. Name — любое, например MONOLITH.
  3. Authentication не трогай — пусть остаётся OAuth.
  4. Нажми Connect — откроется окно «Подключить хранилище», там синяя кнопка Подключить.

Раньше на этом шаге вылезала ошибка «Failed to set up OAuth client registration»: сервер не умел регистрировать клиентов сам. Теперь умеет и окно появляется сразу. Запасной вариант, если что-то пошло не так: Authentication → None — хранилище открыто на чтение и пустит без ключа.

Claude Code

Одна команда в терминале — и всё.

терминал
claude mcp add --transport http monolith https://monolith-mcp.slavin5511.workers.dev

Проверить, что подключился: claude mcp list. Убрать: claude mcp remove monolith.

Cursor

Файл ~/.cursor/mcp.json (на Windows — %USERPROFILE%\.cursor\mcp.json). Если файла нет — создай.

~/.cursor/mcp.json
{
  "mcpServers": {
    "monolith": {
      "url": "https://monolith-mcp.slavin5511.workers.dev"
    }
  }
}

Дальше Settings → MCP: сервер monolith должен загореться зелёным и показать пять инструментов.

Claude Desktop и другие без HTTP

Файл claude_desktop_config.json: Windows — %APPDATA%\Claude\, macOS — ~/Library/Application Support/Claude/. Нужен установленный Node.

claude_desktop_config.json
{
  "mcpServers": {
    "monolith": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://monolith-mcp.slavin5511.workers.dev"]
    }
  }
}

После правки файла перезапусти программу полностью, иначе сервер не появится.

Разрешить ИИ добавлять ссылки

По умолчанию сервер только читает. Чтобы он мог класть найденное в хранилище:

  1. Cloudflare → Workers & Pages → monolith-mcp → Settings → Variables.
  2. Переменная WRITE_ENABLED = 1.
  3. Секрет GITHUB_TOKEN — токен с правом на запись в репозиторий.

Даже после этого ИИ обязан спросить разрешение перед каждым добавлением.

Пароль на сервер

Адрес сервера — вещь непубличная, но если хочется закрыть его совсем: добавь в том же разделе Variables секрет AUTH_TOKEN с любым длинным словом. После этого в клиенте выбирай Bearer Token и вставляй то же слово. Подключение через Connect при этом продолжает работать — оно выдаёт свой ключ и не требует вводить пароль руками.

Как это устроено

Сервер — пара файлов на Cloudflare Workers, без баз и зависимостей. Данные он берёт прямо из репозитория сайта, поэтому хранилище везде одно и то же: что на сайте, то и у ИИ. Логика поиска та же, что в умном поиске сайта. Обновляется сам при каждом изменении репозитория.

Подключение сделано по OAuth 2.1 с саморегистрацией клиента (RFC 7591) и PKCE. Сервер ничего не хранит: выданный ключ — это подписанная строка со сроком годности внутри, поэтому ни базы, ни аккаунтов здесь нет.
